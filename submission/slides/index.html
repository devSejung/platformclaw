Problem

AI가 코드를 바꿔도, 하드웨어 검증은 여전히 끊겨 있습니다

도구 전환

대화, IDE, VM, 빌드 서버, 보드 예약, 이슈 작성, 메신저를 사람이 이어 붙입니다.

소유권 공백

누구의 Agent·세션·작업공간·자격 증명인지 경계가 흐리면 자동화가 위험해집니다.

증거 단절

개인 개발 VM의 build와 보드 제어, 재시도, 보고서가 한 실행으로 추적되지 않습니다.

04 / 13

Execution boundary

개인 Agent는 자신의 Workspace와 선택된 실행 위치만 봅니다

Basic

플랫폼 서버의 격리 Sandbox. 기본값이며 개인 작업공간을 사용합니다.

Assigned VM

사용자에게 할당된 개인 개발 VM과 Workspace에 접속하고 SSH lease를 재사용합니다.

Skills

선택된 target에서 bounded catalog를 읽고 실행 snapshot을 고정합니다.

선택한 VM 연결이 실패해도 더 약한 실행 위치로 조용히 fallback하지 않습니다.

05 / 13

Knox policy

DM은 개인 Agent로, Group Room은 공유 Agent로

DM

  • 사전 Web 로그인을 확인
  • 개인 main session으로 route
  • 개인 VM 선택을 유지

Group Room

  • 방별 Agent를 idempotent provision
  • 개인 VM·개인 credential 금지
  • 플랫폼 Sandbox에서 실행

대화 채널은 transport이고, 실행·소유권 정책은 Control Plane이 소유합니다.

Credential boundary

브라우저는 비밀번호를 저장하지 않고, 실행기는 한 번만 받습니다

Control Plane

암호화된 credential envelope와 endpoint binding, revision을 관리합니다.

Execution plugin

local one-shot grant를 redeem하고 SSH master lease에만 사용합니다.

  • HttpOnly browser session
  • 관리자 소유 Global MCP 정책 + 사용자별 encrypted credential
  • URL credential, endpoint mismatch, stale revision은 fail closed

Business value
